  from scipy.integrate import solve_ivp

❯ can f be a system of linear equations in numpy matrix                         

⏺ Yes. f just has to return an array the same shape as y, so a linear system is
  dy/dt = A @ y:

  import numpy as np
  from scipy.integrate import solve_ivp

  A = np.array([[-0.5,  1.0],
                [ 0.2, -0.3]])

  def f(t, y):
      return A @ y

  sol = solve_ivp(f, (0, 20), y0=np.array([1.0, 0.0]),
                  t_eval=np.linspace(0, 20, 200))
  # sol.y has shape (2, 200): one row per state variable

  Three things worth knowing:

  1. Affine systems (dy/dt = A @ y + b): just return A @ y + b. Same for
  time-varying, A(t) @ y.
  2. Jacobian: for stiff methods (BDF, Radau, LSODA) pass jac=A directly — it's
  constant, so no function needed. Big speedup.
  3. Higher-order ODEs: convert to first-order by stacking derivatives into y,
  then A is the companion matrix.

  If your y is naturally a matrix rather than a vector, flatten it inside f and
  reshape on the way out — solve_ivp requires 1-D state.

  Next: write your A and run the snippet above with your own y0.

  condition than the paper's two-light relation.

  Boundaries land as you'd want: the switch at $t = T$ makes $g_2 = 1$, i.e.
  each phase is half-open $[,\cdot,,,\cdot,)$. Measure-zero for the ODE, but
